# OSIRIS Mobile — One-page brochure copy

## Headline
**Global intelligence. Pocket COP.**

## Subhead
A hardened Android shell for the open-source OSIRIS platform — live flights, maritime, hazards, cyber, and OSINT tools on a GPU map.

## Three pillars
1. **Field-ready UI** — Layers, Markets, Intel, Search, RECON in the native mobile layout.
2. **Security by default** — HTTPS-only, origin allowlist, SSL fail-closed, optional location.
3. **Same API as the dashboard** — 57 public endpoints. No special internal tier.

## Audience
Analysts, researchers, and operators who need a glanceable common operating picture on Android.

## Responsible use
Active RECON only against infrastructure you own or have written authorization to test.
